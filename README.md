# Rainfall-Prediction-using-LSTM

Rainfall prediction stands as a vital tool that has ability to foresee when and the extent to which rain will fall in a specific area. Predicting rainfall isn't just about knowing when to carry an umbrella; it's about providing invaluable insights that drive agricultural planning, manage water resources, and ensure preparedness for potential disasters. The significance of rainfall prediction is also evident at airports, where it presents challenges by affecting critical aspects of aviation and operations. This challenge arises from the lack of accurate rainfall prediction. By leveraging data of Tribhuvan International Airport (TIA), collected from Nepal Government department of hydrology and meteorology between 1999 to 2022, the project aims to compare and predict rainfall class implementing LSTM, with the goal of improving accuracy.

# Installation

It is recommended to use a virtual environment to install this repository. Example commands for windows:

```sh
python -m venv .venv
.venv\scripts\activate
pip install -r requirements.txt
```
